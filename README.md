# Lapster: The before and after Master

Official name: **Lapster: The before and after Master**

## Pricing (consistent across landing, paywall, and license code)
- **Trial:** 2 days free
- **Lifetime:** $4.99, billed once after the trial if not cancelled
- No yearly plan. No other prices.

## Files
- `index.html` — Landing page with wordmark, header, demo slider, pricing, and paywall
- `app.js` — License logic (localStorage trial start + lifetime purchase simulation)
- `privacy.html` — Privacy policy (required for Play Console)
- `manifest.json` + `sw.js` + icons — PWA ready for PWA Builder
- `PLAY_LISTING.txt` — Suggested Play Store listing text

## Hosting
Deployed to GitHub Pages for HTTPS so the privacy policy URL and PWA Builder package can be generated for Google Play Console.
